# 弹出菜单设计约定

适用范围：会话栏中的“新建工作台”和“语言”菜单。新增同类操作菜单时，先沿用这里的定位、外观和交互规则；对话框、提示气泡和工作区内的专用浮层另行设计。

## 定位

- 菜单打开时以触发控件的实际位置为锚点，保留 6px 间隔。视口四周至少留 8px，空间不足时将菜单位置限制在可见区域内；窗口尺寸改变后重新定位。
- 新建工作台菜单默认从加号按钮左边缘向下展开。标签栏宽度变化时，已打开的菜单跟随按钮移动。
- 桌面语言菜单从语言按钮右边缘对齐，向下展开。
- 宽度不超过 600px 时，语言按钮位于会话操作菜单内。空间足够时，语言菜单在会话操作菜单左侧，并与语言按钮纵向对齐；左侧空间不足时，在会话操作菜单下方展开。

## 外观与内容

- 同类菜单共用面板背景、边框、圆角、阴影和条目样式。菜单内边距为 5px，条目最小高度为 38px；悬停和键盘焦点使用主题强调色背景。
- 条目文字左对齐，图标或选择标记占固定位置，避免各行文字起点跳动。图标用于区分操作时，与该操作在界面其他位置的图标保持一致：SSH 使用终端图标，SFTP 使用文件夹图标。
- 当前语言项显示勾选标记及强调色。语言选项为“自动”“中文”“English”；自动项遵循浏览器语言。
- 工作台名称随界面语言切换；语言选项保留各自的显示名称。装饰性图标对辅助技术隐藏，菜单项的可访问名称由文字提供。

## 交互

- 加号单击直接新建 SSH 工作台；长按 500ms、右键或键盘 `↓`、菜单键、`Shift+F10` 打开工作台菜单。指针移动超过 8px 时取消长按。
- 工作台菜单打开后聚焦首项；`↑`、`↓` 循环移动，`Home`、`End` 跳到首末项，`Escape` 关闭并返回加号，`Tab` 关闭菜单。选择条目后执行对应操作并关闭菜单。
- 点击语言按钮切换语言菜单。选择语言后应用设置并关闭菜单；`Escape` 关闭语言菜单，手机端的会话操作菜单仍保持打开。点击菜单外部会同时关闭语言菜单和会话操作菜单。
- 触发按钮用 `aria-expanded` 表示菜单状态；菜单和菜单项使用对应的 ARIA 角色，语言选项用 `aria-checked` 表示当前选择。

## 实现位置与验证

- 菜单结构：`frontend/index.html`；定位和语言交互：`frontend/src/main.ts`；新建菜单交互：`frontend/src/session-create-menu.ts`；共同样式：`frontend/src/style.css`。
- 对应浏览器回归：`tests/browser/dashboard.spec.ts`，覆盖图标、桌面锚点、手机并排位置及 320px 视口下的下方位置。

此文档记录当前已实现的会话栏菜单规则。将规则用于其他菜单前，需核对该菜单的触发方式、内容长度和所在滚动容器。
